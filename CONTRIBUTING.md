# Contributing

To report any bugs to help improve XtMapper please create an [issue](https://github.com/Xtr126/XtMapper/issues).

To share your thoughts on XtMapper or ask any questions please create a post in [discussions](https://github.com/Xtr126/XtMapper/discussions).

## Pull requests

Contributions are welcome. Please open a pull request with a clear description of the change and any relevant issue. For changes that affect the app's behavior or appearance, include steps to verify the change; screenshots are helpful for UI changes.

Please split large changes into smaller, focused pull requests where possible.

See [BUILDING.md](BUILDING.md) for the project build instructions. Keep changes focused and preserve the project's existing code and attribution conventions. 

## Translations

Help us translate on [Crowdin](https://crowdin.com/project/xtmapper/) or GitHub. Translation contributions are credited in [CONTRIBUTORS.md](CONTRIBUTORS.md).
